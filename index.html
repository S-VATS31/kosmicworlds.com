Capabilities

From sparse input to an explorable world.

Kosmic Worlds is being built around a simple idea: the model should infer a place, preserve it through time, and remain responsive to what happens next.

Core signals

Built around multimodal world priors.

The long-term ambition is a system that can take partial evidence, infer a world, and let the user branch into possible futures.
